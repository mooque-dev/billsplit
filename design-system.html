Yuwol Split · Design System

shadcn/ui-compatible tokens and components in plain CSS (ds.css). Same token names and data-state conventions as shadcn, so the React + Tailwind port is a direct swap. Light/dark follow the OS.

Rules

  1. Never hard-code colors — always hsl(var(--token)).
  2. Build screens from the components below. App layout may only use tokens + these components.
  3. State lives in data-state (on/off/active/paid); color intent in data-tone.
  4. Touch targets ≥ 2rem (dense) or 2.5rem (default). Keep focus rings visible. Everything reachable by keyboard.
  5. New component? Add it to ds.css and to this page first, then use it.
